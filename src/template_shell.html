📐 2. የሒሳብ ቀመሮች፣ የቁጥሮች ምደባ እና ጂኦሜትሪ (High-Accuracy Mathematical Formulas)

G7 & G8 Formulas

🔢 የቁጥሮች ስብስብ (Number Sets)

  • • Natural (መደበኛ): ℕ = {1, 2, 3, 4, ...}
  • • Whole (ደቂቅ/ሙሉ): W = {0, 1, 2, 3, ...}
  • • Integers (ሙሉ ቁጥሮች): ℤ = {..., -2, -1, 0, 1, 2, ...}
  • • Rational (አመክንዮአዊ): ℚ = { a/b | a, b ∈ ℤ, b ≠ 0 }
  • • Irrational: Non-terminating, non-repeating decimals (π, √2, √3)
  • • Real (እውነተኛ): ℝ = ℚ ∪ ℚ'

📊 የርክክብ እና የኃይል ህጎች (Laws of Exponents)

  • • aᵐ · aⁿ = aᵐ⁺ⁿ
  • • aᵐ / aⁿ = aᵐ⁻ⁿ (a ≠ 0)
  • • (aᵐ)ⁿ = aᵐⁿ
  • • (ab)ᵐ = aᵐ · bᵐ
  • • a⁰ = 1 (a ≠ 0)
  • • a⁻ᵐ = 1 / aᵐ
  • • √(a · b) = √a · √b
  • • √(a / b) = √a / √b (b > 0)

📐 የጂኦሜትሪ ዙሪያ፣ ስፋት እና ይዘት ቀመሮች (Perimeter, Area & Volume)

Rectangle (አራት ማዕዘን): Perimeter: P = 2(l + w)
Area: A = l · w
Triangle (ሦስት ማዕዘን): Area: A = ½ · b · h
Pythagoras: a² + b² = c²
Circle (ክብ): Circumference: C = 2πr = πd
Area: A = πr² (π ≈ 3.14 or 22/7)
Trapezoid (ትራፔዞይድ): Area: A = ½(a + b) · h
(a, b = parallel bases)
Rectangular Prism (ፕሪዝም): Volume: V = l · w · h
Surface Area: SA = 2(lw + lh + wh)
Cylinder (ሲሊንደር): Volume: V = πr² · h
Surface Area: SA = 2πr² + 2πrh
Parallelogram: Area: A = b · h
Perimeter: P = 2(a + b)
Cube (ኩብ): Volume: V = s³
Surface Area: SA = 6s²

  • • ዳአማት እና የሃ (Da'amat & Yeha): ከክርስቶስ ልደት በፊት በ10ኛው ክፍለ-ዘመን የተመሰረተ የጥንት ስልጣኔ፤ የየሃ የድንጋይ ቤተ-መቅደስ።
  • • የአክሱም ስልጣኔ (Axumite Empire): ዓለም አቀፍ የባህር ንግድ፣ የአክሱም ሀውልቶች፣ የሳንቲም ህትመት፣ እና የኢትዮጵያ የፊደል አጻጻፍ ስርዓት።
  • • የላሊበላ ውቅር አብያተ-ክርስቲያናት (Zagwe Dynasty): በአንድ ወጥ እሳተ-ጎመራዊ ድንጋይ ተፈልፍለው የተሰሩ የዓለም ቅርስ አስደናቂ ህንፃዎች።
  • • የገዳ ስርዓት (Gadaa System): የኦሮሞ ህዝብ ባህላዊና ዴሞክራሲያዊ የአስተዳደር ስርዓት፤ በየ8 ዓመቱ በሰላማዊ መንገድ ስልጣን የሚተላለፍበት የዩኔስኮ ዓለም አቀፍ ቅርስ።
  • • የዓድዋ ድል (Battle of Adwa - March 1, 1896): ዳግማዊ አጼ ምኒልክ እና እቴጌ ጣይቱ ብጡል የመሩት የኢትዮጵያ ጀግኖች ጦር የጣሊያንን ቅኝ ገዢ ጦር ድል በማድረግ የነፃነት ተምሳሌት የሆነበት ቀን።

🧠 5. የSQ3R የጥናት ሳይንሳዊ ስነ-ዘዴ መመሪያ (The SQ3R Pedagogical Engine)

Cognitive Science

የSQ3R የጥናት ስልት በ1946 እ.ኤ.አ. በታዋቂው አሜሪካዊ የትምህርት ሳይኮሎጂስት ዶ/ር ፍራንሲስ ሮቢንሰን (Dr. Francis P. Robinson) በኦሃዮ ስቴት ዩኒቨርሲቲ የተፈጠረ ሲሆን፣ ተማሪዎች የሚያጠኑትን ትምህርት በረጅም ጊዜ ማህደረ-ትውስታ (Long-Term Memory) እንዲይዙት የሚያስችል የተረጋገጠ ሳይንሳዊ ስርዓት ነው።

1. Survey (ቅኝት)
5–10% የጥናት ጊዜ

አጠቃላይ ይዘቱን፣ ርዕሶችን፣ ስዕላዊ መግለጫዎችን እና ማጠቃለያዎችን በፍጥነት በመቃኘት የአዕምሮ ካርታ (Schema) መገንባት።

2. Question (ጥያቄ)
10% የጥናት ጊዜ

ንባብ ከመጀመር በፊት ርዕሶችን ወደ "ለምን? እንዴት? ምንድን ነው?" ጥያቄዎች በመቀየር አዕምሮ ንቁ አፈላላጊ እንዲሆን ማድረግ።

3. Read (ንባብ)
35–40% የጥናት ጊዜ

ያዘጋጀናቸውን ጥያቄዎች ለመመለስ በማሰብ በጥልቀት ማንበብ፤ ቁልፍ ቃላትን እና ቀመሮችን ማስተዋል፤ ምሳሌዎችን ደረጃ-በደረጃ መረዳት።

4. Recite (ማስታወስ)
25–30% የጥናት ጊዜ

መጽሐፉን በመዝጋት የተነበበውን በራስ ቃላት ጮክ ብሎ መናገር ወይም በፍላሽ ካርድ መሞከር (Active Recall)።

5. Review (ፈተና)
15–20% የጥናት ጊዜ

በየሳምንቱ እና በየወሩ ፈተናዎችን መለማመድ (Spaced Repetition)፤ ስህተቶችን መርምሮ የጎደሉ ክፍሎችን እንደገና ማጥናት።
